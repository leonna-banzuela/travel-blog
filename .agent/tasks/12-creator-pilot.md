# Task 12 — Creator pilot

Status: Not started (later phase)

Depends on: Task 11 and owner approval to expand scope

## Objective

Pilot controlled contributions from 2–3 New Zealand creators without opening public registration.

## Actions

- Define content ownership, publication permission, attribution, editing, removal, and joint-promotion agreements.
- Add creator profiles, credited stories, social links, and clearly labelled links to each creator's own mailing list.
- Implement a controlled submission -> review -> revision -> publish workflow.
- Add owner authentication and per-creator authorization only if remote submission is required; otherwise use a controlled private intake.
- Add quotas, media validation, audit records, and tested content backup/restore.
- Usability-test onboarding and publishing with the pilot creators.

## Acceptance criteria

- Each pilot creator can submit content without accessing another creator's drafts.
- Nothing publishes without owner approval.
- Rights, attribution, removal, quotas, and recovery are documented and tested.
- Support effort remains manageable before public expansion.

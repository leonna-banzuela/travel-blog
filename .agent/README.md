# Travel Blog build harness

This folder externalizes the plan and current state so a new Codex session can resume without relying on chat history.

- `instructions/` owns durable project context and working rules.
- `progress/` records only observed work, decisions, evidence, and blockers.
- `tasks/` owns the ordered implementation plan. Each numbered file is one independently verifiable phase.

Start with [`instructions/START_HERE.md`](instructions/START_HERE.md).

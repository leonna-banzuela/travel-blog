# Owner authoring studio boundary

This directory is reserved for the Task 06 owner CMS.

The studio must:

- bind only to `127.0.0.1`/`localhost`;
- validate all content through the canonical schemas;
- write deterministic repository content and processed media;
- remain outside `src/`, `public/`, and the generated `dist/` directory;
- provide no public route, mutation endpoint, login, or signup page.

Do not add implementation here before Task 06. Task 01 establishes only this security boundary.

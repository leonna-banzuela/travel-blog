# Leonna’s Travel Journal v0.1.0

Released 14 November 2026.

The first public release is a map-first, read-only travel journal beginning with Leonna Banzuela’s 1 November 2026 visit to Sandy Beach, Auckland. Readers can explore by map or list, filter stories, open a directly shareable entry, view privacy-conscious media, and see the author and visit date for every story.

The owner CMS remains local-only and is excluded from the public build. GitHub pull requests run the complete verification suite and receive isolated preview deployments before protected `main` can deploy to Cloudflare Workers. The release was verified on mobile and desktop and through a rollback-and-restore drill.
